# Баай

Экономическая настольная игра про Якутию. Покупай города и посёлки, собирай группы, строй дома и отели, разоряй соперников.

**Играть:** https://evsav37.github.io/baai/ (открывается в браузере телефона)

**Файл для игры без интернета:** [dist/baai.html](dist/baai.html) — вся игра в одном файле.

## Как играть с разных телефонов (без интернета)

1. На телефон хоста скачайте и поставьте **[baai.apk](https://github.com/EvsAV37/baai/releases/latest/download/baai.apk)**. Если телефон спросит — разрешите установку из браузера.
2. Включите на нём точку доступа, откройте «Баай» и нажмите **«Создать игру по Wi-Fi»**.
3. Друзья подключаются к этой точке доступа и наводят камеру на QR-код. Игра откроется в браузере, ставить ничего не нужно, подходит и iPhone.
4. Если телефон пишет «Нет подключения к интернету» — выберите «Оставаться на связи».
5. Все в комнате — хост нажимает **«Начать игру»**.

Отвалился игрок — снова сканирует тот же QR (меню → «QR для подключения») и продолжает со своего места.

## Что сейчас готово (этапы 1–4)

- Игра с разных телефонов по Wi-Fi точке доступа: комната с QR, выбор имени и фигурки, переподключение, 15 секунд на ставку в аукционе.
- Игра на одном телефоне: 2–6 игроков передают телефон по кругу.
- Поле из 40 клеток: 22 города Якутии в 8 группах, транспорт, коммуналка, налоги.
- Колоды «Байанай» и «Тюсюлгэ», по 16 карточек.
- Аукцион, залог, обмен, кредит (банк или игрок), Приз Ысыаха, банкротство, ограничение по времени.
- Партия сохраняется в телефоне: можно закрыть и продолжить.
- APK собирается сам на каждое изменение (GitHub Actions) и лежит в Releases.

Дальше: полировка — звуки, анимации, рисунки (этап 5). Полное описание — [docs/baai-spec.md](docs/baai-spec.md).

## Как устроен код

| Файл | Что внутри |
|---|---|
| `js/data.js` | Поле, цены, аренда, тексты карточек |
| `js/engine.js` | Правила игры. Не зависит от экрана, позже будет работать у хоста |
| `js/ui.js` | Экран: рисует поле и отправляет действия в движок |
| `js/net.js` | Игра по сети: комната, QR, хост и игроки |
| `android/` | Приложение хоста: WebView + сервер игры |
| `tools/relay.js` | Тот же сервер на Node.js — для проверки на компьютере |
| `tests/net-e2e.js` | Проверка сети в браузере: хост и два игрока |
| `css/style.css` | Оформление |
| `tests/sim.js` | Автопрогон 2000 партий для проверки правил |
| `tools/build_single.py` | Собирает игру в один файл `dist/baai.html` |
